# AI Threat Detection System

**Detect Phishing URLs with Machine Learning & Explainable AI**

### Overview
A lightweight, intelligent tool to predict whether a URL is **Safe ✅** or **Malicious ⚠️**. Combines cybersecurity insights with ML and SHAP explainability for fast, interpretable predictions.

### Features
- Random Forest-based URL classifier
- Interactive Streamlit web interface
- SHAP feature importance visualization
- Lightweight & fast (works on 4 GB RAM)

### Tech Stack
Python | Scikit-learn | Pandas | Streamlit | SHAP | Joblib

### Quick Start
```bash
git clone <repo-url>
cd AI_Threat_Detection
pip install -r requirements.txt
streamlit run app.py
